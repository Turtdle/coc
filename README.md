# coc

The Lovely clan's stats site, served at https://turtdle.github.io/coc/lovely/ (and https://lovelycoc.com).

Everything under `lovely/` is written by the clan bot's hourly publisher (Turtdle/coc-clan-bot, `site_publish.py`), so don't edit it by hand. It lives in its own repo so the bot's deploy key can only write here, not to the rest of turtdle.github.io.
